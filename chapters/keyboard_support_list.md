# 键盘支持列表

我们的 HHKB QMC 主控支持 HHKB 旗下所有 ANSI 配列的静电容键盘。包括 HHKB Pro2、HHKB BT、HHKB Classic 和 HHKB Hybrid.

支持的具体键盘型号列表如下：

⚠️*对于新款的 HHKB，表格可能未及时更新，请联系作者确认是否支持。*

|    型号     |                说明                 |
| :---------: | :---------------------------------: |
|  PD-KB400W  |    HHKB Professional 2 白色有刻     |
|  PD-KB400B  |    HHKB Professional 2 黑色有刻     |
| PD-KB400WN  |    HHKB Professional 2 白色无刻     |
