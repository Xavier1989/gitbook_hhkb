# README
这是 **HHKB Quad Mode Controller** 的[使用说明文档](https://hhkb.xorlink.com/how_to_use)，皆在帮助大家更好地使用该产品。

产品在使用过程中，有任何问题或建议，欢迎通过[邮件](mailto:xorlink@qq.com)与作者联系。

HHKB QMC（Quad Mode Controller） 支持：
* **USB**
* **Bluetooth LE**
* **Logitech Unifying**
* **Logitech Bolt**

四种连接方式，一个主控全部搞定。

它不仅是首款四模 HHKB 主控，也让 HHKB 成为首个同时支持 USB、BLE、Unifying 和 Bolt 的键盘。

This document provides [instructions](https://hhkb.xorlink.com/how_to_use) for the HHKB Quad Mode Controller and is intended to help users use the product effectively.

If you have any questions, encounter any issues, or would like to provide feedback, please do not hesitate to contact the author by [email](mailto:xorlink@qq.com).
